# T3 Gaming Records

This extension provides a tracking system for highscore and speedrun data of your favorite games.
With it's front end user registration mechanisms, it can be used as sort of a community driven web site.

## Installation

The extension is compatible with the latest TYPO3 CMS version 14.3.
It can be installed with composer:

`composer require dduers/t3-gaming-records`
